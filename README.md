# techpulse
Tech Blog and Article Layout   
This is Probation Task 1 of CCC, developed using HTML and CSS. This project focuses on creating a modern, responsive tech blog with clean typography, article cards, a homepage layout, a single article page, and a trending posts sidebar.

Includes two pages: Blog Homepage and Single Article Reading Page.

It has three main files-
index.html (content of homepage)
article.html (content of article reading)
css.style (for styling both pages)

Features a responsive article grid, blog cards, typography, navbar, and Trending Posts sidebar.

No JavaScript, frameworks, or external libraries are used.

Clean, well-structured,code.
